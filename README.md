## Internship Process
1. Shared my internship status on LinkedIn, tagging @CodeAlpha.
2. Selected tasks from the App Development task list.
3. Built each project and uploaded the source code to GitHub in a repository named CodeAlpha_ProjectName.
4. Posted a video explanation of each project on LinkedIn with the GitHub link.
5. Submitted the completed tasks through the Submission Form.

## Tasks I Completed
### Task 1: Flashcard Quiz App
A flashcard app for studying. Each card has a question on the front and the answer on the back, with a "Show Answer" button. Users can move between cards using Next and Previous buttons, and can add, edit and delete flashcards. The interface is simple and clean.

### Task 2: Random Quote Generator
An app that shows a random quote with the author's name every time it opens or when the "New Quote" button is clicked. It has a clean and minimal interface.
